# Test data

No system ROMs are included. Firmware needed by a test is supplied through
`INSPECCY_ROM_DIR` or the runner's `--rom-dir` option.

The [manifest](manifest.json) lists every checked-in binary fixture and image
reference, its SHA-256 and its provenance. All retained sample programs were
confirmed by their author as their own; the small synthetic fixtures have
inspectable sources. These files are covered by the project's BSD 2-Clause
license. Emulator-generated references record expected emulator behavior;
they are not independent evidence of hardware accuracy.

| Location | Origin and purpose |
| --- | --- |
| `sna/` | Twelve short instruction tests in zero-filled RAM. `sna/src/generate.py` reproduces them byte-for-byte using Python. |
| `nex/` | Small NEX workloads with assembly under `nex/src/`. The loading bitmap is generated by `generate_loading_screen.py`. |
| `dck/` | A two-chunk cartridge built from `dck/src/lros_smoke.asm` by `make_lros_smoke.py`. |
| `dotcmd/` | A short read-wait test with assembly source, a generated geometric NXI image, and a repeated 0..255 byte sequence for VFS tests. |
| `copper/` | Assembly pairs comparing raster effects with static software-rendered images. |
| `resume/` | The synthetic assembly workload used to test split runs, audio, video and coverage. |
| `programs/` | The author's compiled examples: NullForm, Touching the Sun, rtzx, snownononext, sup, VVGIntro, nxiview and Parallel Visions. These exercise larger program workloads; their application sources are not part of Inspeccy. |
| `../refs/video/` | Rendered references for the matching assembly tests under `../asm/video/`. |
| `../refs/nex/` | The reference output for the synthetic NEX loading-screen test. |
| `../refs/z80_fingerprint/` | Text records of opcode disassembly and timing, with assembler encoding checks. |

To check the portable generators and inventory, run from the source root:

```sh
python tests/python/test_fixtures.py
```

To rebuild an assembly fixture, run sjasmplus from its `src/` directory.
For example, `sjasmplus trace_workload.asm` under `nex/src/` writes
`nex/trace_workload.nex`. The DCK wrapper invokes sjasmplus itself.
Use the installed assembler version deliberately when updating binaries.

New binary inputs need a source or an explicit provenance record. Keep captures,
ROMs, downloaded programs and output dumps out of this directory. A change to
a reference image needs a rendering explanation and review, not just a new hash.
